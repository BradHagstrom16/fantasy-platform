CSS Changes (3 rules)

/* 1. Navbar — stick to top */
.navbar {
position: sticky;
top: 0;
z-index: 1030;
}

/* 2. Subnav — stick below navbar */
.game-subnav {
position: sticky;
top: 58px; /* navbar height on desktop */
z-index: 1020;
}

/* 3. Mobile navbar is shorter */
@media (max-width: 991px) {
.game-subnav { top: 52px; }
}

Key Details

  • z-index 1030/1020 — navbar on top of subnav, both above page content. Matches existing wc-mobile-sticky-bar layer (1030).
  • No body padding needed — sticky keeps elements in document flow (unlike fixed).
  • Hamburger expansion — works automatically. The expanded menu pushes the subnav down because both are in flow.
  • Non-game pages — no subnav exists, so only the navbar sticks. No special handling needed.
  • Top values — 58px desktop / 52px mobile. Will verify exact heights in the dev server before shipping.
